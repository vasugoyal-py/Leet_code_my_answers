# LeetCode My Answers

This repository contains my personal solutions to LeetCode problems that I have solved while learning and practicing algorithms and data structures.

## Purpose

- Track my problem-solving progress.
- Improve my understanding of algorithms and data structures.
- Build consistency for coding and interview preparation.
- Keep a record of solutions for future reference.

## Organization

Solutions are stored in the `Final` folder and organized by problem number:

```text
Final/
  1-10/
    1/
      solution.py
```

Each problem has its own numbered folder. The `on_git` folder is an intake folder for new numbered files or folders. Run `organize_on_git.py` to route them into `Final` automatically.

## Languages

Currently includes:

- Python
- SQL

More languages may be added as I learn them.

## Note

These solutions represent my work at the time I solved each problem. As I continue learning, I may revisit older solutions to improve their efficiency, readability, or coding style.
